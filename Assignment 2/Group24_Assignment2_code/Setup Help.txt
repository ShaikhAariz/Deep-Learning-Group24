PREREQUISITES & DEPENDENCIES

This code was written in Python 3. No machine learning frameworks 
(like scikit-learn or TensorFlow) were used, as per the instructions.

Please ensure the following standard libraries are installed:
- numpy
- pandas
- matplotlib

You can install them via:
pip install numpy pandas matplotlib

HOW TO RUN THE CODE

To ensure the relative file paths work correctly, please run the 
scripts from the ROOT DIRECTORY of this unzipped folder.

1. Open your terminal or command prompt.
2. Navigate into the unzipped folder:
   cd path/to/MainFolder

3. To run the Classification tasks:
   python classification.py

4. To run the Regression tasks:
   python regression.py

NOTE: The scripts will automatically generate and save all the required plots at plot/classification or plot/regression.
